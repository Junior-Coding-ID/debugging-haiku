# Debugging Haiku

A 5-7-5 haiku about the most maddening kind of bug: two strings that look identical, a watch pane that insists the value is false, and the culprit — a non-breaking space hiding in plain sight.

```
Two strings look the same
The watch pane reads false again
A space that won't break
```

Running `main.ts` writes this exact haiku (83 characters, 3 lines) to `entry.txt` in the output directory.
